# Cânon Etíope Tewahedo

## Regra editorial

O projeto adotará como referência primária a lista canônica publicada por fontes institucionais da Igreja Ortodoxa Etíope Tewahedo.

A lista deverá ser normalizada sem apagar diferenças de nomenclatura.

## Objetivos

- registrar os 81 livros;
- preservar nomes tradicionais;
- registrar variantes de nomenclatura;
- distinguir cânon restrito e discussões sobre cânon amplo;
- registrar fontes para cada identificação.

## Importante

Não assumir que nomes como "Meqabyan", "Macabeus", "Esdras", "Sinodos" ou outros termos possuem equivalência automática entre tradições.

Cada equivalência deverá ser demonstrada por fonte.
