# Quality Assurance

## Testes obrigatórios

- integridade dos livros;
- integridade dos capítulos;
- integridade dos versículos;
- IDs únicos;
- referências existentes;
- fontes existentes;
- links válidos;
- imagens licenciadas;
- Unicode;
- Ge'ez;
- PDF;
- bookmarks;
- hyperlinks;
- páginas;
- metadados.
