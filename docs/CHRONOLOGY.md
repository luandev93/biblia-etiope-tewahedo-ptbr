# Cronologia

## Regra fundamental

A ordem cronológica é uma reconstrução editorial e não deve ser confundida com a ordem canônica.

Para cada obra serão armazenados:

- data provável de composição;
- data provável de redação final;
- período histórico retratado;
- tradição textual;
- grau de certeza;
- fontes da datação.

## Graus de certeza

HIGH
MEDIUM
LOW
DISPUTED
UNKNOWN

## Regra

Quando a datação for controversa, apresentar a controvérsia.

Nunca inventar precisão cronológica.
