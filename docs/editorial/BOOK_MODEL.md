# Modelo Editorial de Livro

Cada obra do projeto terá uma ficha documental própria.

## Identidade

- ID interno
- nome oficial da fonte primária
- nome em português
- nomes tradicionais
- nome em Ge'ez
- transliteração
- identidade textual
- estado de identificação

## Cânon

- camada canônica
- posição na lista institucional
- relação com listas históricas
- variantes de agrupamento

## Cronologia

A cronologia não será apresentada como verdade absoluta.

Serão separados:

1. data de composição;
2. data de redação final;
3. período histórico retratado;
4. ordem cronológica editorial;
5. grau de certeza.

## Texto

- idioma original;
- tradição textual;
- manuscritos;
- edições;
- estado de aquisição;
- estado de verificação.

## Tradução

A tradução PT-BR será uma camada independente do texto-fonte.

Ela terá:

- versão;
- revisão;
- notas;
- variantes;
- referências.

## Direitos

Nenhum texto, tradução ou imagem entra no PDF final sem que o status
de direitos/licença esteja registrado.

## Regra crítica

O campo `identity_status` nunca poderá ser usado para esconder incerteza.

Quando houver disputa acadêmica, ela será preservada.
