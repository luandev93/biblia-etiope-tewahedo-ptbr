# Arquitetura do Projeto

## Princípio

O PDF é um artefato gerado.

A fonte principal do projeto é o corpus documental estruturado.

## Camadas

1. Fontes
2. Inventário canônico
3. Corpus original
4. Tradução PT-BR
5. Aparato crítico
6. Cronologia
7. Metadados
8. Ilustrações
9. Build
10. QA

## Fluxo

FONTES
↓
INVENTÁRIO
↓
CORPUS
↓
TRADUÇÃO
↓
REVISÃO
↓
BUILD
↓
QA
↓
PDF

## Regra

Nenhum conteúdo deverá existir apenas dentro do PDF.
