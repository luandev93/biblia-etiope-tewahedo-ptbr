# Banco de Fontes

Cada fonte deverá possuir um identificador único.

Formato:

SRC-0001
SRC-0002
SRC-0003

## Campos mínimos

- source_id
- autor
- título
- instituição
- data
- idioma
- edição
- páginas
- URL
- DOI/ISBN quando existir
- licença
- tipo
- confiabilidade
- observações

## Hierarquia

PRIMARY
ACADEMIC
INSTITUTIONAL
REFERENCE
SECONDARY

## Regra

Nenhum texto poderá ser marcado como VERIFICADO sem fonte registrada.
